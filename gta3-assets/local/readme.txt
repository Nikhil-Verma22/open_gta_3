 СИСТЕМНЫЕ ТРЕБОВАНИЯ
____________________

ВНИМАНИЕ!!! Не гарантируется нормальная работа игры на ОС Windows Vista.

ВНИМАНИЕ!!! Игра не будет работать, если язык и региональные стандарты
вашей ОС установлены на Французский, Немецкий, Испанский или Итальянский.

Программное обеспечение:

В Grand Theft Auto III используется Microsoft DirectX 8.1.
Поддерживаются следующие операционные системы:

	Windows 98
	Windows 98 Second Edition
	Windows Millennium
	Windows 2000 Professional (Workstation)
	Windows XP (Home и Professional)

Следующие оперативные системы НЕ поддерживаются:

	Windows 95
	Windows NT (все версии)
	Mac OS
	Linux
	BEOS

Минимальные требования к оборудованию:
	
	Процессор Intel Pentium III или AMD Athlon 450 МГц
	96 Мб оперативной памяти
	4-скоростной CD/DVD дисковод
	700 Мб свободного дискового пространства
	Видеокарта минимум с 16 Мб памяти и драйвером, совместимым с DirectX 8.1
	Звуковая карта, совместимая с DirectX 8.1
	Клавиатура
	Мышь

Рекомендуемые требования к оборудованию:
	Процессор Intel Pentium III или AMD Athlon  700 МГц  или более производительный


	Не менее 128 Мб оперативной памяти
	8-скоростной CD/DVD дисковод 
	700 Мб свободного дискового пространства
	Видеокарта с 32 или более Мб памяти и аппаратной поддержкой DirectX 8.1
	Звуковая карта, совместимая с DirectX 8.1 и поддерживающая объемное звучание
	Геймпад (для USB или игрового порта)
	Клавиатура
	Мышь

 ОБЩИЕ СВЕДЕНИЯ
_________

DirectX:
Для запуска и функционирования игры Grand Theft Auto III требуется 
Microsoft DirectX 8.1,  поэтому мы рекомендуем использовать драйверы видео- 
и звуковых карт, совместимые с DirectX 8.1, или устройства с аппаратной 
поддержкой DirectX 8.0 / DirectX 8.1.

Windows XP:
Мы рекомендуем использовать драйверы, выпущенные производителем оборудования
и позволяющие настраивать его параметры, вместо стандартных драйверов Microsoft, 
устанавливаемых по умолчанию.

Оперативная память:
Для функционирования игры Grand Theft Auto III требуется не менее 96 Мб памяти. 
Для  достижения оптимальной производительности требуется не менее 128 Мб 
(рекомендуется 256 Мб).

Работа других приложений:
При разработке игры Grand Theft Auto III особое внимание было уделено оптимальному
использованию всей мощности компьютера, поэтому перед запуском игры мы рекомендуем 
завершить работу всех остальных приложений.

Видеопамять:
Для функционирования игры Grand Theft Auto III требуется видеокарта минимум с 16 Мб 
видеопамяти. Запуск игры на компьютере с меньшим объемом видеопамяти невозможен.

Процессоры AMD K6/2 и K6/III:
На компьютерах, оснащенных этими процессорами, производительность игры 
Grand Theft Auto III может быть неприемлемо низкой.

_______________________________________________________________________

 УСТАНОВКА
__________

Поместите диск с игрой Grand Theft Auto III в CD/DVD дисковод. 
Если у вас включена функция автозапуска, установка игры начнется автоматически. 
Если функция автозапуска отключена, перейдите в корневую папку диска 
Grand Theft Auto III с помощью Проводника и запустите файл setup.exe вручную.

Основной объем
Для установки игры Grand Theft Auto III требуется приблизительно 1 Гб дискового 
пространства.

Сохраненные игры
Grand Theft Auto III размещает папку с сохраненными играми GTA3 USER FILES 
в папке "Мои документы" текущей учетной записи. Таким образом  данные каждого
из пользователей (в Windows 2000 или Windows XP) хранятся отдельно.

Удаление
При удалении игры Grand Theft Auto III папки MP3, SKINS и GTA3 USER FILES 
остаются на вашем компьютере. Вы можете удалить их вручную.

_______________________________________________________________________

 НАСТРОЙКА
__________

Способ вывода звука
Выбор драйвера для звуковой карты может влиять на производительность игры.
При недостаточной производительности попытайтесь использовать другое  значение 
параметра, например Software, MSS Fast, RSX, Direct Sound Hardware или Direct 
Sound Software.

Динамическая модель акустики
Чтобы незначительно повысить производительность игры, отключите пункт 
"Динамическая модель акустики" в меню "Звук".

Шлейф
Отключив эффект шлейфа от движущихся объектов в меню настройки экрана, вы повысите 
производительность игры Grand Theft Auto III.

Разрешение экрана
Выбор меньшего разрешения экрана позволяет увеличить производительность 
игры на маломощных компьютерах. С целью увеличения производительности вы 
также можете использовать 16-разрядную палитру вместо 32-разрядной.

 РЕШЕНИЕ ПРОБЛЕМ
________________

Windows XP + видеокарты nVIDIA (и некоторые другие марки):
При работе с Windows XP был обнаружен ряд проблем с изображением, возникающих
как при отображении меню, так и в ходе самой игры.
Эти проблемы связаны непосредственно с системой Windows XP.
Проблемы можно устранить путем обновления файла d3d8.dll. (Версия на официальном
диске Windows XP, которая вызывает эти проблемы, имеет номер 5.1.26000.0,
без ошибок работают 5.1.2600.15 и 5.1.2600.29.)
В настоящий момент нам известен только один способ обновления .dll файла - 
установка обновления Windows XP "Компьютер не может перейти в ждущий или 
спящий режим, если работает программа-заставка на базе Direct3D (Q306676)" со 
следующего сайта: http://download.microsoft.com/download/whistler/Patch/Q306676/WXP/EN-
US/Q306676_WXP_SP1_x86_ENU.exe.
Это обновление может входить в состав официального обновления Windows XP Service Pack, 
Windows XP Compatibility Update или DirectX 8.1.

Видеокарты Power VR Kyro 2
Игра не полностью поддерживает эти видеокарты в связи с особенностями
обработки графики, поэтому некоторые текстуры могут отображаться некорректно.
Мы рекомендуем использовать эти видеокарты в режиме 32-разрядной палитры, поскольку
в режиме 16-разрядной возможна редкая проблема с буфером глубины. Также 
мы советуем настроить параметры изображения нижеописанным образом.
	Перейдите в окно дополнительных параметров экрана
	Откройте страницу Direct 3D и создайте новый профиль для gta3.exe
	В этом профиле установите следующие значения параметров:
		DISABLE W buffer
		ENABLE external depth / stencil buffer format
		ENABLE Direct 3d / stencil buffer format
		ENABLE depth / stencil buffer format
		ENABLE depth / stencil buffer loading

Звуковые карты Aureal
Мы получили много сообщений о неустойчивой работе игры со звуковыми
картами Aureal. Эти звуковые карты сняты с производства, и новые драйверы 
для них не выпускаются. У нас и в прошлом возникали проблемы с поддержкой 
звуковых карт Aureal, и имеющиеся на сегодняшний день драйверы не позволяют 
решить их. Попробуйте использовать другие интерфейсы звука (напр. Software, 
MSS Fast, RSX, Direct Sound Hardware или Direct Sound Software).

Звуковые карты, встроенные в материнскую плату
Некоторые встроенные звуковые карты не имеют аппаратного буфера, что 
приводит к нестабильному функционированию игры Grand Theft Auto III.
В таком случае запустите программу Microsoft DXDIAG и примите предложение 
использовать  программный буфер. Использование программного буфера позволяет 
встроенным звуковым картам работать с игрой Grand Theft Auto III.

Дефрагментация жесткого диска
Если производительность игры периодически снижается во время езды на транспортных
средствах, возможно, у игры возникли проблемы со своевременной загрузкой данных 
с жесткого диска. Для повышения скорости обмена данными рекомендуем 
регулярно запускать программу дефрагментации жесткого диска.
